# Puls SPA

Корпоративная платформа мотивации, биллинга KPI и геймификации для
операторов контакт-центра. Прототип на моковых данных: бэкенда нет,
всё состояние живёт в браузере и сбрасывается при перезагрузке.

## Запуск

```
npm install
npm run dev        # разработка
npm run build      # сборка в dist/
npm run typecheck  # строгая проверка типов
```

## Устройство

```
src/
  types.ts          единственный источник типов предметной области
  mockData.ts       48 операторов, миссии, тесты, магазин, журнал
  store.tsx         всё состояние в одном reducer
  lib/calc.ts       формула баллов и коинов — только здесь
  lib/format.ts     форматирование чисел — только здесь
  components/
    ui/             примитивы: панели, кнопки, таблица, модалка, салют
    layout/         каркас: боковое меню, верхняя панель, быстрый переход
    views/          пятнадцать экранов
    modals/         прохождение теста
```

## Решения, которые стоит знать

**Формула живёт в `lib/calc.ts` и больше нигде.** Как только её можно
посчитать в двух местах, через месяц она посчитана по-разному, и
ведомость перестаёт сходиться с тем, что видит оператор.

```
Итоговые баллы = качество × 0.4 + КВЗ × 0.3 + часы × 0.3 − штрафы × 0.5
Коины          = баллы ÷ 2 × множитель квалификации
```

Множитель применяется к коинам, а не к баллам: баллы сравнивают
операторов между собой и должны оставаться сопоставимыми.

**Всё состояние в одном reducer.** Почти каждое действие затрагивает
несколько сущностей сразу: покупка меняет баланс, склад и журнал;
прокрутка колеса — билеты, баланс, историю и уведомления. Разнеси это по
трём хукам, и однажды одно из трёх забудут обновить.

**Приз колеса выбирается до анимации.** Обратный порядок — «куда
остановилось, то и выпало» — сделал бы результат заложником частоты
кадров. Шансы в интерфейсе показаны те же, по которым идёт жеребьёвка.

**Цвет ячейки таблицы задаётся свойством `tone`, а не классом снаружи.**
Базовый `dark:text-zinc-300` и переданный `text-caution` имеют одинаковую
специфичность, и побеждает тот, что стоит позже в собранной таблице
стилей: порядок в атрибуте класса ничего не решает.

## Ограничения прототипа

Данные моковые и генерируются с фиксированным зерном — рейтинг одинаков
при каждой загрузке, иначе невозможно обсудить конкретную строку.
Состояние не сохраняется между перезагрузками: это витрина механики, а не
рабочая система.
