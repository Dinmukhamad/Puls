# Облачная озвучка голосового тренажёра

Google Cloud Text-to-Speech и Azure Speech подключаются к существующему API Puls.
Выбор озвучки доступен перед звонком и в настройке голоса во время тренировки.
Для сравнения можно подключить оба сервиса. По умолчанию выбирается Google,
если он настроен, затем Azure; без настроенных сервисов работает голос браузера.

Первый голос Google — `ru-RU-Chirp3-HD-Charon`, Azure — `ru-RU-DmitryNeural`.
Это начальный выбор для прослушивания, а не результат сравнения на слух.
Русский язык поддерживается обоими сервисами.

## Подключить Google Cloud

1. В своём [проекте Google Cloud](https://console.cloud.google.com/) подключите
   billing и включите **Cloud Text-to-Speech API**. Это отдельный сервис;
   ключ Gemini / Google AI Studio не заменяет доступ к Cloud TTS.
2. В **APIs & Services → Credentials** создайте API key и ограничьте его
   использование **Cloud Text-to-Speech API**. Ключ будет использовать сервер,
   поэтому ограничение по HTTP referrer браузера к нему не подходит.
3. Откройте [API Puls на Render](https://dashboard.render.com/web/srv-dacvr6710e5c73cngbv0),
   **Environment → Add Environment Variable**. Добавьте
   `GOOGLE_TTS_API_KEY` со значением ключа. Не добавляйте его в статический
   сервис Puls, `VITE_*`, исходный код или сообщения чата.
4. Выберите **Save and deploy**, чтобы API получил новое значение. Одного
   **Save only** недостаточно до следующего развёртывания.
5. Откройте `/training/voice`, выберите облачную озвучку Google и нажмите
   «Прослушать голос». Затем проверьте реальную реплику в тренировке.

При необходимости другой голос задаётся серверной переменной
`GOOGLE_TTS_VOICE`. Список голосов и поддержка функций зависят от модели.
Приложение передаёт Chirp 3 HD обычный текст и получает MP3, не навязывая
неподдерживаемые SSML-стили.

Google требует billing даже при использовании бесплатного лимита.
По [тарифу Cloud TTS](https://cloud.google.com/text-to-speech/pricing)
Chirp 3 HD включает 1 млн символов в месяц; превышение оплачивается.
Облачные квоты и расходы контролируются в вашем проекте Google Cloud.

## Подключить Azure вместо Google или для сравнения

1. Создайте ресурс **Azure Speech**, для пробы выберите **Free F0**, если
   он доступен в вашей подписке и регионе.
2. В ресурсе **Keys and Endpoint** возьмите ключ и обозначение региона,
   например `westeurope`.
3. В Environment того же сервиса API на Render добавьте
   `AZURE_SPEECH_KEY` и `AZURE_SPEECH_REGION`. При необходимости можно задать
   `AZURE_TTS_VOICE`; исходное значение — `ru-RU-DmitryNeural`.
4. Нажмите **Save and deploy** и выберите Azure в тренажёре.

У [Azure Speech F0](https://azure.microsoft.com/en-us/pricing/details/speech/)
указан бесплатный лимит 500 тысяч символов нейроозвучки в месяц.

## Обработка данных и проверка

Ключи читаются только из серверных переменных окружения. В браузер передаётся
готовое аудио, имя сервиса и голоса. Синтезу передаётся сохранённая реплика
виртуального водителя либо фиксированный текст образца. Ответ оператора,
микрофонная запись и произвольный текст клиента в сервис синтеза не отправляются.

Запрос реплики проверяет владельца попытки и номер сохранённого хода.
Повторяющиеся аудиофрагменты кешируются на сервере; ошибки поставщика и
ограничения запросов обрабатываются без потери этапа разговора. Если облачная
озвучка не сработала, интерфейс сообщает о переходе на голос устройства.
Запрос и воспроизведение отменяются при остановке, начале записи и выходе.

Проверки с имитацией API и аудио подтверждают соединение компонентов и обработку
ошибок. Проверка настоящего голоса требует действующего доступа к провайдеру
и прослушивания на устройстве. Отсутствие ключа не считается успешным тестом
Google или Azure.
