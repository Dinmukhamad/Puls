Это не стилистика, а сломанный рендер:

* `00-base-layout.css:585` — `var(--gold)` пустой, градиент вырождается.

* **Маршрут после F5.** `navigateTo()` пишет hash и `localStorage['pulse-last-view']`;

* **Экранирование.** `esc()` применяется 661 раз; поведение не менялось.
* **Права доступа, API-контракты, бизнес-логика.** Не затронуты: изменения
  ограничены `css/**`, `index.html`, `js/theme-init.js`.

## 2. Архитектура дизайн-системы

Четыре уровня. Каждый следующий не имеет права переопределять цвета
предыдущего и не использует `!important`.

```
css/tokens.css                            ← значения (палитра, шкалы)
css/src/base/**                           ← reset, каркас, типографика
css/src/components/05-ui-primitives.css   ← компоненты (.ui-btn, .ui-field, .ui-table…)
css/src/components/10-ui-system.css       ← прикладные блоки (.ui-page-header, .ui-filter-bar…)
css/src/views/**                          ← только композиция и раскладка
```

Порядок склейки в `scripts/build-frontend.mjs` — по имени файла, поэтому
префикс `05-` гарантирует, что примитивы идут после базы и до прикладного слоя.

### Правила

1. Цвет, отступ, радиус, тень, длительность анимации берутся **только** из токена.
2. `!important` в новом коде запрещён. Стиль не применился — чинится специфичность вьюхи.
3. Один класс на компонент, модификаторы через `--модификатор` (`.ui-btn--primary`).
4. Каждый интерактивный элемент реализует default / hover / active / focus-visible /
   disabled / loading.
5. Смысл не передаётся одним цветом: у статусов есть точка-маркер и подпись,
   у дельт — стрелка (`.ui-delta--up::before`).

## 3. Токены

`css/tokens.css`, 195 переменных.

* **Палитра** — системная iOS: фон `#F2F2F7`, поверхность `#FFFFFF`,
  текст `#1C1C1E` / `#636366` / `#8E8E93`, разделитель `#D1D1D6`,
  акцент `#007AFF`. Тёмная тема — `#000000` / `#1C1C1E` / `#2C2C2E`,
  разделитель `#38383A`, акцент `#0A84FF`.
* **Фирменный слой Puls** сохранён: `--accent-secondary` (индиго) и
  `--accent-violet` остаются акцентами геймификации.
* **Графики** — `--chart-1…8`, различимы и по тону, и по светлоте.
* **Сайдбар** переведён с тёмной плиты на светлый iPadOS-sidebar
  (полупрозрачный `--sidebar-bg` + `--blur-nav`), активный пункт — мягкая
  синяя заливка вместо градиента.
* **Типографика** — системный стек (`-apple-system` → SF Pro на Apple,
  Segoe UI на Windows). Базовый кегль 15px: админка плотнее iOS-приложения.
  Поля ввода — 16px, иначе iOS Safari зумит страницу при фокусе.
* **Шкалы** — отступы шагом 4px, радиусы 6→28px по уровню компонента,
  тени нейтральные (без цветного ореола), длительности 100–320 мс.
* **Safe area** — `--safe-top/bottom/left/right` из `env()`.
* **`prefers-reduced-motion`** обнуляет все длительности разом в одном месте.

### Legacy-алиасы

Секция `LEGACY ALIASES` в конце каждой темы сохраняет все старые имена
(`--tx`, `--surface`, `--r-md`, `--ok-soft`, `--nav-bg` и т.д.), на которые
ссылаются 2653 `var()` по проекту. **Удалять нельзя** до завершения этапа 5.
Проверка отсутствия регрессии:

```bash
grep -rhoE "var\(--[a-zA-Z0-9_-]+" css/src js/src index.html | sed 's/var(//' | sort -u > /tmp/used.txt
grep -oE "\-\-[a-zA-Z0-9_-]+\s*:" css/tokens.css | sed 's/\s*:$//' | sort -u > /tmp/defined.txt
comm -23 /tmp/used.txt /tmp/defined.txt   # должны остаться только локально-скоупные
```

Локально-скоупные (объявляются внутри вьюхи или инлайн) и это нормально:
`--level-color`, `--world-accent`, `--mission-progress`, `--an-health`,
`--prize-color`, `--wheel-prize-color`, `--progress-days`, `--progress-height`,
`--pc-*`, `--rc-*`.

## 4. Компоненты

`css/src/components/05-ui-primitives.css`, 981 строка.

| Группа | Классы |
|---|---|
| Действия | `.ui-btn` (`--primary/secondary/outline/ghost/danger/plain`, `--sm/md/xl/block/loading`), `.ui-icon-btn` |
| Ввод | `.ui-field`, `.ui-label` (`--required`, `__optional`), `.ui-input`, `.ui-textarea`, `.ui-select`, `.ui-search`, `.ui-check` (+`--radio`), `.ui-switch` |
| Навигация | `.ui-segment`, `.ui-tabs` / `.ui-tab`, `.ui-chip`, `.ui-breadcrumbs`, `.ui-stepper` |
| Статусы | `.ui-badge` (`--neutral/success/danger/warning/info/accent`), `.ui-delta` |
| Поверхности | `.ui-card`, `.ui-kpi`, `.ui-kpi-grid` |
| Таблицы | `.ui-table-wrap`, `.ui-table` (`--pin-first`, `--cards`), `.is-num`, `.is-truncate`, `.ui-pagination` |
| Состояния | `.ui-skeleton` (`--text/title/row/card`), `.ui-state` (+`--error`), `.ui-progress`, `.ui-alert` |
| Оверлеи | `.ui-overlay`, `.ui-modal` (`--sm/lg`), `.ui-sheet`, `.ui-popover`, `.ui-menu-item`, `.ui-toast`, `.ui-tooltip` |
| Прочее | `.ui-avatar`, `.ui-visually-hidden`, `.ui-num`, `.ui-truncate` |

Решения, которые стоит знать до использования:

* **Таблицы.** Строка 48px, шапка 40px и `position: sticky`. Числовые
  колонки — `.is-num` (правое выравнивание + `tabular-nums`, разряды
  выстраиваются друг под другом). Широкие таблицы — `--pin-first`.
  На ширине ≤767px `.ui-table--cards` превращает строки в карточки,
  подпись колонки берётся из `data-label` — горизонтальный скролл не нужен.
* **Модалки.** На ширине ≤640px `.ui-modal` автоматически становится
  bottom sheet: прижимается к низу, скругляется сверху, кнопки футера
  разворачиваются в колонку на всю ширину. Отдельная разметка не нужна.
* **Loading у кнопки.** `.ui-btn--loading` гасит содержимое, рисует спиннер
  и ставит `pointer-events: none` — повторное нажатие не создаёт дубль
  запроса на уровне CSS. Дизейбл в JS всё равно обязателен.
* **Фокус.** Кольцо `var(--focus-ring)` через `:focus-visible` — видно при
  навигации с клавиатуры и не мешает мыши. `outline` не убран, а заменён.

## 5. Порядок дальнейшей миграции

Этапы идут строго по возрастанию риска. Каждый — отдельный PR.

**Этап 1 — фундамент. Сделано.**
Токены, примитивы, системный шрифт, `viewport-fit=cover`, тема по системной
настройке, устранены 8 неопределённых переменных и контраст сайдбара.

**Этап 2 — каркас. Сделано.**
Раскладка каркаса вынесена в `css/src/layout/10-app-shell.css` — единственное
место, где живут позиционирование сайдбара, топбар, таб-бар и safe-area.

* Добавлены `.app-topbar` (sticky, заголовок раздела, колокольчик, тема)
  и `.app-tabbar` (мобильная нижняя навигация).
* `body` переведён на `--font-main` / `--fs-body`: до этого стоял
  `font-family: 'Inter'` и `font-size: 14px`, из-за чего шрифтовые токены
  не применялись вообще.
* Мобильная навигация: было 15 иконок без подписей в горизонтальном скролле,
  стало 4 основных раздела с подписями + «Ещё», открывающее шторку с полным
  списком. Приоритеты — `TABBAR_PRIORITY` в `js/src/app/20-app-shell.js`.
* Права не дублируются: список разделов таб-бара всегда приходит из
  `allowedViewsForRole()`, разметка пунктов клонируется из сайдбара.
* Клики по разделам переведены на делегирование — пункты таб-бара создаются
  после логина, статический биндинг их не поймал бы.
* `!important` в базовом слое: 10 → 1 (остался только `[hidden]`),
  в `zzz-ui-ux-hardening.css`: 4 → 0.
* Добавлен `tests/frontend/app-shell.test.mjs` — 13 тестов в jsdom
  на реальном бандле (роли, лимит пунктов, активное состояние, Escape,
  aria-expanded, отсутствие инлайновых цветов).

**Этап 2.1 — осталось.** Свёрнутый режим сайдбара по кнопке проверен только
тестами; ширины 1280/1440/1920 требуют визуальной проверки в браузере.

**Этап 3 — демонтаж слоёв-заплаток.** По одному файлу за PR, в порядке
`zzz-ui-ux-hardening` → `zz-corporate-trust-system` → `90-visual-polish` →
`40-coins-tests-wheel-overrides`. Каждое правило либо переносится в примитив,
либо удаляется как более не нужное. Цель — 238 `!important` → 0.

**Этап 4 — таблицы и фильтры.** Перевод всех таблиц на `.ui-table`,
всех панелей фильтров на `.ui-filter-bar` + `.ui-chip`. Здесь исчезают
99 `!important` из `20-rating-shop-dashboard.css`.

**Этап 5 — вьюхи по разделам.** Аналитика → сводка → операторы/группы →
коины → магазин → тесты → колесо → миссии. Миссии последними: 254 hex
на четыре файла, это самая большая переработка.

**Этап 6 — снятие legacy-алиасов.** Только после того, как `comm` из §3
покажет, что старые имена больше не используются.

**Этап 7 — производительность.** `styles.css` 508 КБ и `app.js` 860 КБ
разбиваются по разделам, тяжёлые вьюхи (миссии, колесо, аналитика) уходят
в ленивую загрузку.

## 6. Проверки перед коммитом

```bash
ruff check app tests     # линт бэкенда
.venv/bin/pytest -q      # 277 тестов
npm run build            # пересборка бандлов (обязательно, CI сверяет)
```

После правки `css/src/**` или `js/src/**` — обязательно `npm run build`
и подъём `?v=` в `index.html`, иначе статика придёт из immutable-кеша.
