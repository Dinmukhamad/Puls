# «Гонка недели»

Раздел для операторов: «Результаты → Гонка недели» (`/race`). Оператор видит своё место среди всех
операторов недели, сколько баллов не хватает до соседа выше и до 1–3 мест, свой отрыв от соседа ниже
и какие показатели подтянуть, чтобы подняться.

## Что на странице

- **Ваше место** — место из числа участников, баллы из максимума недели (100), изменение места к
  прошлой неделе. Плитки: «До N-го места» (сколько баллов и кто там), «Отрыв от N-го места» (сосед
  ниже) и «До призовой тройки», если вы ниже 3-го места. Лидеру показан отрыв от второго.
- **Тройка лидеров** — первые три места с баллами и тем, на сколько они впереди вас.
- **Что подтянуть**:
  - «Подняться на N-е место (Имя Ф.)» — разрыв в баллах и показатели, каждого из которых по
    отдельности хватит, чтобы обогнать: текущее значение → нужное и сколько баллов это даст. Первым
    идёт самый маленький шаг относительно цели.
  - Если одного показателя мало — набор показателей, начиная с тех, где теряется больше всего баллов.
    Если разрыв за неделю не закрыть — сколько ещё можно добрать.
  - «До призовой тройки» — то же для 3-го места, если оно не совпадает со следующим шагом.
  - «Где вы теряете баллы» — каждый показатель: недобор до максимума, значение, цель, баллы и цена
    единицы («+1 шт/ч = +1,25 балла»). Незагруженный показатель — «нет данных»; в подсказки он не
    попадает.
- **Таблица гонки** — все операторы недели: место, имя, баллы, разница с вами и изменение места; своя
  строка выделена. В длинной таблице видны тройка лидеров и места вокруг вас, кнопка «Показать всех»
  раскрывает весь список.
- Внизу — как оплачиваются места (см. «Призы») и, для идущей недели, что места ещё изменятся.

## Какая неделя и откуда места

- По умолчанию открыта текущая неделя, как только загружен хотя бы один её показатель; иначе —
  последняя рассчитанная. Неделю можно сменить.
- Рассчитанная неделя (предварительный расчёт или закрытая) берёт баллы из итогов недели. Нерассчитанная
  считает их на лету из загруженных показателей теми же правилами (`scoring.score_week`), как прогноз
  в кабинете, с подписью «Неделя идёт · по загруженным данным».
- Места — как в недельном расчёте: при равных баллах место делится (1, 2, 2, 4). «Подняться на место»
  значит набрать на 0,01 балла больше, чем у того, кто его занимает.
- Подсказки считаются только по показателям самого оператора. Баллы показателя — `max_points × min(значение
  / цель, 1)`, для «меньше — лучше» — `max_points × min(цель / значение, 1)`. Нужное значение округляется
  в сторону цели до 0,1 (штуки — до целого), и выигрыш пересчитывается по округлённому значению.

## Имена

Решение от 17.10.2026: в гонке недели и в таблице «Конкурса месяца» оператор видит других операторов
как «Имя Ф.» (`visibility.ranking_name`). Сотрудники, которым видны операторы, по-прежнему видят полные
ФИО. Во вкладке «Рейтинг → Недели» оператор, как и раньше, видит только свою строку. Порядок слов в ФИО
определяется по отчеству: «Имя Отчество Фамилия» или «Фамилия Имя Отчество» (`visibility.short_name`).

## Призы

При конкурсе раз в месяц (`contest_period = month`, по умолчанию) места недели не оплачиваются: внизу
страницы сказано, что призы за 1–3 места — в «Конкурсе месяца», и каждый балл недели идёт в его сумму.
При еженедельном конкурсе показаны бонусы за 1–3 места недели.

## API

`GET /api/v1/rating/race?week_id=` — только для операторов, остальным 403. Ответ `RaceOut`
(`app/schemas/rating.py`): `week`, `live`, `period`, `prizes`, `participants`, `max_points`, `me`,
`next`, `behind` (с `lead`), `podium` (пороги 1–3 мест среди остальных), `standings` (все, `gap` = их
баллы минус ваши), `metrics` и `advice` (`room`, `next` с `options` и `plan`, `podium` с `plan`).
Расчёт — `app/services/race.py`.
