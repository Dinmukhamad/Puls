# Структура разделов Puls

## Общий принцип

В боковом меню Puls отображаются только **крупные разделы**.

Внутри каждого раздела находятся вкладки и подразделы.

Например, вместо отдельных пунктов:

* Тесты
* Миссии
* Driver Simulator

в меню будет один раздел:

**Обучение**

А уже внутри:

**Тесты | Миссии | Driver Simulator**

Это позволит добавлять новые функции без постоянного увеличения бокового меню.

# Главная логика структуры

У Puls должно быть несколько постоянных верхнеуровневых направлений:

**Главная**

**Команда**

**Аналитика**

**Производительность**

**Обучение**

**Мотивация**

**Система**

Но роль пользователя определяет, какие из них он видит.

Например:

### Оператор

**Главная → Результаты → Обучение → Награды → Профиль**

### СВ

**Главная → Команда → Аналитика → Обучение → Рейтинг и мотивация → Профиль**

### Менеджер

**Главная → Команда → Аналитика → Производительность → Обучение → Мотивация → Отчёты**

### Admin

**Главная → Пользователи и структура → Производительность → Аналитика → Обучение → Мотивация → Система**

Это позволяет Puls расти дальше.

Если завтра появится новый учебный модуль, он добавляется в **«Обучение»**.

Если появится новая игровая механика, она добавляется в **«Мотивацию»**.

Если появится новый тип аналитики, он добавляется в **«Аналитику»**.

Боковое меню при этом не превращается в бесконечный список.
