# Компоненты shadcn в `src/components/ui/`

Сайт держит свою дизайн-систему в `src/components/ui.tsx` и CSS-токенах (`src/styles/tokens.css`). Готовые
компоненты в стиле shadcn (Tailwind + TypeScript) кладутся отдельно, в папку `src/components/ui/` — как в
shadcn CLI. Так их легко найти, обновить из исходника и не смешать с компонентами сайта. Файл `ui.tsx` и
папка `ui/` уживаются: `import … from "./ui"` по-прежнему берёт `ui.tsx`, а примитив подключается по
полному пути — `./ui/calendar` или `@/components/ui/calendar` (алиас `@` → `src`, в `vite.config.ts` и
`tsconfig.json`).

## Tailwind — только для этой папки

`src/styles/ui.css` (подключён в `main.tsx` после `app.css`):

- **без Preflight** — сброс стилей у сайта один, в `app.css`; для кнопок примитивов в `ui.css` есть свой
  маленький сброс с нулевой специфичностью;
- утилиты генерируются **только из `src/components/ui/`** (`source(none)` + `@source`), поэтому классы
  страниц вроде `grid` или `hidden` не получают правил Tailwind;
- утилиты **не в каскадном слое**: как классы сайта, они сильнее правил по тегам (`button { color: inherit }`);
- токены shadcn (`--background`, `--foreground`, `--primary`, `--border`, `--muted-foreground`, …) внутри
  `[data-slot="calendar"]` — это токены сайта, светлая и тёмная тема работают сами;
- у сайта есть свой класс `.grid` (отступ 24 px) — внутри примитива он обнулён.

Новому примитиву: положить файл в `src/components/ui/`, задать в `ui.css` его токены по `data-slot` и
проверить, не совпадают ли его классы с классами сайта (как `grid`).

## Календарь

`src/components/ui/calendar.tsx` — месяц с анимацией перелистывания, быстрый переход к месяцу и году,
режимы `single`, `range`, `multiple`, недоступные даты и отметки событий. Переведён на русский, неделя с
понедельника. Зависимости: `framer-motion`, `@tabler/icons-react`, `clsx`, `tailwind-merge`. Пример —
`calendar.demo.tsx`.

На сайте он стоит в `DateRangePicker` (и в `DatePicker`/`DateTimePicker`): поле, подсказка о периоде,
«Отмена / Применить», «Сегодня / Очистить» и логика страниц прежние, сменилась сетка дней. Календарь
грузится отдельным файлом при первом открытии (около 60 КБ сжатыми), основной файл сайта не вырос; пока
он грузится, в окне «Загрузка календаря…», а фокус переходит на день, как только сетка появилась.
