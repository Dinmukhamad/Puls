# Puls — геймификация и обучение операторов

Puls — внутренний сайт для операторов колл-центра (службы заботы о водителях).
Он превращает ежедневную работу и обучение в игру: за хорошие показатели и
пройденные материалы оператор получает коины, растёт в уровне, поднимается в
рейтинге и тратит награды в магазине бонусов.

## Зачем он нужен

- **Мотивация.** Работа становится видимой и соревновательной: каждая неделя —
  маленький конкурс со своим рейтингом, номинациями и наградами.
- **Обучение.** Новички и опытные операторы учатся на тренажёрах, которые
  повторяют настоящие рабочие инструменты, — без риска ошибиться с реальным
  водителем.
- **Прозрачность для руководителей.** Все показатели команды собраны в одном
  месте: по дням, неделям и месяцам, по группам и отдельным сотрудникам.

## Для кого

| Кто | Что получает |
|---|---|
| Оператор | личный кабинет, прогресс и уровни, коины, рейтинг, магазин бонусов, обучение и игровые миссии |
| Тренер | создание учебных материалов, тестов и миссий, результаты обучения операторов |
| Супервайзер | своя группа: показатели, заявки на бонусы, начисления, загрузка отчётов |
| Руководитель | вся команда: аналитика, расчёт и публикация итогов недели, настройки наград |

## Что умеет сайт

**Мотивация и награды**
- Еженедельный рейтинг: баллы за показатели (качество, эффективность, норма
  часов, звонки в час), места, номинации недели.
- Коины за результаты недели и обучение; личный и командный кошелёк.
- Уровни и достижения по заработанным коинам.
- Магазин бонусов с заявками, которые одобряет руководитель.
- Мини-игры: колесо удачи и розыгрыши.

**Обучение**
- Курсы, тесты и материалы, которые тренер собирает в студии.
- **Мой город** — 3D-город с миссиями: оператор проходит главы обучения,
  а город растёт вместе с его прогрессом.
- **Учебная CRM** — копия рабочего окна обращений, где можно тренироваться на
  реальных сценариях.
- **Driver Simulator** — тренажёр водительского приложения: выход на линию,
  заказы, навигация по карте. Помогает оператору понимать, что видит водитель.

**Аналитика**
- Показатели команды по дням, неделям и месяцам, сравнение групп и операторов.
- Загрузка месячных отчётов прямо на сайте: файлы отчётов перетаскиваются в
  окно, а сайт сам раскладывает данные по дням и неделям.
- Журнал действий и экспорт отчётов.

Сайт работает на компьютере и телефоне, ставится как приложение (PWA),
поддерживает светлую и тёмную тему.

## Технологии

**Сервер**
- Python, FastAPI
- SQLAlchemy 2 (async), Alembic — миграции базы
- PostgreSQL (SQLite для локальной разработки)
- Pydantic — проверка данных
- APScheduler — автоматические задачи по расписанию
- openpyxl — чтение отчётов Excel
- JWT и bcrypt — вход и хранение паролей

**Интерфейс**
- React 18, TypeScript, Vite
- TanStack Query, React Router
- Three.js — 3D-город «Мой город»
- MapLibre GL — карты в Driver Simulator
- собственная дизайн-система на CSS (полупрозрачное «стекло» в стиле iOS),
  без CSS-фреймворков

**Тесты**
- pytest — сервер
- Node test runner — интерфейс

## Используемые ресурсы

- **OpenStreetMap, OpenFreeMap** — карты и тайлы для Driver Simulator
- **OSRM (routing.openstreetmap.de)** — построение маршрутов
- **Photon (komoot)** — поиск адресов
- **Telegram-бот** — подтверждение входа в Driver Simulator
- **3D-модели Kenney и Quaternius** (CC0) — здания, машины и персонажи города
- **qrcode, jsQR** — QR-коды для подтверждения доступа к учебным сайтам
