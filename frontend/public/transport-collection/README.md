# Transport Collection — 20 original 3D models

10 passenger cars, 4 commercial trucks, 3 motor boats and 3 yachts.

Generic original vehicle designs, not licensed replicas of real manufacturers.
Artistic models with approximate dimensions. Units: meters. Y up, +X forward.
GLB includes geometry and PBR materials. Use a viewer or editor supporting the glTF 2.0 format.
Individual files are in dist/assets; transport-collection.zip contains the pack.
inventory.json provides the file list, dimensions, triangle counts and sizes.

Browser viewer: serve dist with any static web server. All Three.js dependencies
are vendored; no external API, analytics, accounts or network textures are used.
Three.js MIT license: dist/vendor/LICENSE.three.txt.
